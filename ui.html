접근성 개선 팁

💡 명도 대비 개선 팁 (색상 진하게 하지 않는 방법)

  • 1. 텍스트 크기 키우기 - 16px 이상으로 키우면 3:1 기준 적용 (가장 추천)
  • 2. 배경 밝게 조정 - 배경을 더 밝게 (#F0F0F0, #F5F5F5) 변경
  • 3. 테두리 추가 - 1px solid 테두리로 요소 구분 명확화
  • 4. 그림자 효과 - box-shadow로 깊이감 추가하여 대비 개선

🎨 색상 독립성 개선 팁 (색상만으로 구분하지 않기)

  • 1. 텍스트 굵기 차별화 - 선택(Bold) vs 미선택(Regular)으로 구분
  • 2. 밑줄/상단선 추가 - 선택된 항목에 underline 또는 top border 추가
  • 3. 아이콘 추가 - 선택 상태에 체크(✓) 또는 화살표(→) 아이콘 표시
  • 4. 크기 차별화 - 선택된 항목을 살짝 크게 또는 패딩 증가
  • 5. 테두리 두께 - 선택(2px) vs 미선택(1px)으로 구분
